# Java Fundamentals – Console Application
This is a Java console application developed for the first project of the CMPE343 course. The project focuses on the fundamentals of Java programming using a single class with multiple methods. It includes basic operations such as array statistics, matrix operations, encryption/decryption, and a mini-game.

## Features

### General
- Console-based UI with ASCII Art welcome message
- Single `.java` file with many methods
- Turkish character support
- Menu-based structure that loops until termination
- JavaDoc comments included

### [A] Array Statistics
- Input: array size and double values
- Outputs: arithmetic mean, geometric mean, median, harmonic mean
- Harmonic mean calculated using recursion
- Input validation included

### [B] Matrix Operations
- Operations: transpose, inverse, matrix multiplication, element-wise multiplication
- Input: dimensions and elements of one or two matrices
- No use of predefined matrix libraries
- Handles invalid or singular matrices properly
- Formatted output of results

### [C] Text Encryption/Decryption
- Caesar Cipher implementation
- Shift value range: [-26, 26]
- Encryption and decryption handled separately
- Non-alphabetic characters remain unchanged
- Invalid inputs handled gracefully

### [D] Tic-Tac-Toe HotSeat
- Turn-based play (X and O)
- Valid move checking
- Board display after each move
- Detects win or tie
- Displays final result and number of moves

### [E] Terminate
- Ends the program safely

## Technologies Used
- Java
- ASCII Art
- Caesar Cipher algorithm
- Matrix operations implemented from scratch
- JavaDoc for documentation
- GitHub for collaboration

## Setup
1. Clone this repository.
2. Open the `.java` file in any Java IDE.
3. Run the program in terminal or console.
4. Follow on-screen instructions to navigate the menu.
